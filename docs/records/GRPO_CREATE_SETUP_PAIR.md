# 先全部创建再准备：GRPO一对真实对照（2026-10-26）

**新模式真实验证通过：关闭→开启各一次完整GRPO，共14个新沙箱、378个原动作，开启组1822个采样点。** 创建完成后才启动准备和采样，原任务、检查及清理均按预期完成。

本对控制程序整轮为27.618→34.699秒，增加25.64%；新增“全部创建完成至控制程序结束”窗口为24.706→26.623秒，增加7.76%。这两个数按各自范围保留，不用后者替换前者。

## 实验条件与正确性

两组都使用[同一新调度](GRPO_CREATE_SETUP_IMPLEMENTATION.md)：七个创建并发，全部创建并登记后，再并发进行各guest的准备，全部准备完成后执行原七条路径。开启组每guest先部署采样并等首点，再检查和上传；关闭组跳过采样。

两组相同2 CPU／4096 MiB、16 GiB私有卷、源镜像及冻结任务，0.1秒guest-only轻量采样对比完全关闭，默认回收保持。没有host周期采样、PSS、文件驻留查询、服务指标、缓存控制或额外等待。

- 原189动作／组，原路径、顺序、退出码、关键输出、最终补丁与两组一致性通过。
- 原官方检查每实例仍为0通过、2失败，结果原样保留；采集及平台重放通过不改写该任务结果。
- 14个实际沙箱ID各不相同；无平台／采集失败、重试或额外组。
- 关闭组没有采样控制调用、周期／边界内存记录或伪造曲线。
- 自有沙箱、私有服务、两份成功卷、挂载、loop和准备缓存完成原清理，源服务回到停止状态。

## 实际顺序已隔离创建与准备

每组28个源码／检查／上传调用均在“全部创建完成”和“全部准备完成”标记之间，且每guest仍按原顺序执行。首个准备命令比最后创建返回晚1.452毫秒（关闭）／200.035毫秒（开启）；开启组先部署采样器，因此源码检查更晚开始。

开启组七个采样会话开始于全部创建完成后0.571～1.164毫秒；各自首点就绪回执均早于该guest的源码检查。全部准备完成后约0.45毫秒才派发首个原任务，两组均无提前任务。

这次没有“早guest采样／上传与其他创建重叠”的情况。与旧十对不同，新曲线不覆盖早guest等待其余创建的区间；仍覆盖准备、原任务、最终检查及删除前采样。

### 整轮增加7.080秒发生在哪里

以下互不重复的实际host时间段之和，精确等于原控制程序整轮；表中四舍五入：

| 阶段 | 关闭/秒 | 开启/秒 | 开启减关闭/秒 |
| --- | ---: | ---: | ---: |
| rollout前控制工作 | 0.051907 | 0.049071 | −0.002836 |
| rollout开始至全部创建完成 | 2.859900 | 8.026826 | **+5.166926** |
| 全部创建完成至全部准备完成 | 2.195441 | 2.251960 | +0.056519 |
| 准备完成至首个任务派发 | 0.000446 | 0.000455 | +0.000009 |
| 首个任务派发至最后下载结束 | 16.574885 | 18.151448 | **+1.576563** |
| 最后下载至全部分支检查完成 | 5.544170 | 5.522786 | −0.021384 |
| 检查后的工作与最终清理 | 0.391526 | 0.696132 | +0.304606 |
| 合计 | 27.618274 | 34.698678 | **+7.080404** |

该分解用执行器首个任务派发标记，上表“原动作及下载窗口”用原控制调用首尾，两者起点相差不足1毫秒，原定义均保持。

约5.17秒的创建增量发生在本项目采样部署之前，本次尚未开始的周期采样不能直接解释这段增量。创建仍有波动，具体外部等待没有服务分段指标，不指定其原因。创建后另增加1.916秒，主要出现在原动作／下载窗口及最终清理；这是一对固定先后顺序的观察，任务波动与稳定采样影响还需同模式重复才能进一步区分。

因此，本轮证明了新顺序能隔离创建期间的准备活动，给出了该顺序下的初步开销。它与旧顺序的速度差异尚未做同条件对照。[旧三对](GRPO_LIGHT_REPEATS.md)和[旧十对](GRPO_LIGHT_TEN_PAIRS.md)仍单独保留，新旧调度不混算。

## 直接采集成本与曲线

七个采样器各260～261点，共1822点，最大采样间隔0.107922秒，全部正常退出并回收。采样器合计1.402287 CPU秒，各自约占一个核心的0.66%～0.82%；各采样器峰值RSS为16.11～16.86 MiB。RSS含共享部分，不当作host净增物理内存。

开启组35次阻塞采样控制调用累计4.024469秒，考虑彼此重叠后的墙钟并集为0.704558秒；它与准备、收尾等阶段重叠，不再加到整轮上。最终并发清理为0.241623→0.541106秒，多0.299483秒，已计入上述时间。
