mincore在两个guest退出、本次磁盘采样器及私有服务停止之后、卷卸载之前执行。这样保留文件供查询，同时避免自有日志写入干扰镜像的稳定性检查。没有为采样暂停运行中的guest。

同期统计组`file`前后均约14.127 GiB；清单驻留量未超过它，未检测到记账不足。统计组还覆盖清单之外的文件缓存，不能只凭这一比较证明所有页都在组内。清单也不包含已删除文件或ublk块设备自身的缓存。所有文件只用`mmap(PROT_NONE)`和mincore查询驻留，没有读取文件内容。

输入RAM镜像与其内部文件的文件系统缓存是不同的缓存对象，不能因为内容相关就按同一个文件合并；同一设备号/inode的绑定路径或硬链接则只计一次。host `file`包含`shmem`，二者不相加。

## PSS核对与准备成本

六次双VMM观测的PSS之和为605.941–713.738 MiB。每次都保存两个进程的身份和各自PSS，排除多计进程、漏掉分支或PID复用。全组PSS还包括服务和控制程序，分别报告；PSS不涵盖所有未映射的文件缓存。

创建第一个guest之前，host `file`同步基线已为14.127 GiB，全流程观测峰值14.149 GiB。大部分file来自公共输入准备，不能由这次曲线接近单沙箱的结果直接推导共享比例。guest的Cached是另一层数据，本次只保存标记检查前后的meminfo快照，不绘成连续guest曲线。

host采集线程整段使用0.870 CPU秒，其中周期计数读取累计0.262秒。102文件mincore另用1.037 CPU秒。本次没有关闭采样的对照，不据这些局部成本计算任务减速。
