## 四种用时分开比较

百分比计算为`(开启 − 关闭) / 关闭`。本次按先开启、后关闭各一次，没有增加重复轮次；下表是这一对观测，不是重复实验的均值。

| 指标 | 开启host采集 | 关闭host采集 | 开启组相对变化 |
| --- | ---: | ---: | ---: |
| 41个实际工具动作累计 | 5.645009秒 | 5.716448秒 | −1.25% |
| 单沙箱后缀回放墙钟 | 2.405943秒 | 2.613069秒 | −7.93% |
| 双沙箱后缀并行墙钟，直到两者完成 | 2.440050秒 | 2.793756秒 | −12.66% |
| 任务控制程序墙钟 | 46.022631秒 | 32.397224秒 | +42.06% |

任务控制程序包括VM创建／恢复、监控控制调用、额外功能和官方检查、任务后查询及沙箱／快照清理，不包含前置输入和私有服务准备。**42.06%对应控制程序墙钟，不是工具时延增幅。** 本次没有观察到工具累计用时增加；负百分比按原值报告，不解释为采样使任务提速。

开启组在两次后缀结束后的PSS、设备与运行中普通文件查询共直接计时11.633秒，位于任务控制程序内；最终普通文件查询另用1.760秒，位于该控制程序之外。关闭组均不执行这些查询。控制程序剩余时间差未进一步归因，不能把所有差值都算给周期采样线程。

日常查看工具、guest内存和page cache曲线仍使用普通轻量配置。41动作共享恢复对照用于需要设备驻留和记账核对的实验，不是每个任务必须重复的准备步骤。

## 新选项默认不改变原入口

host入口默认`--host-sampling on`。只有`--matched-task`可显式关闭；普通完整任务、空闲短恢复及专用探针不能误用此选项。源服务健康、启动磁盘超过50 GiB及原资源保护仍是这项24 GiB实验的条件。

```bash
export ASB_AGENTENV_SOURCE_SERVICE=asb-source-rebuilt-20261018T160925Z-2726362
bash scripts/run-host-file-monitor.sh configs/platform-prettier6604-host-file.json \
  --matched-task --host-sampling off
```

入口不负责启动或替换源服务。关闭组只生成任务计时报告`timing-report/summary.json`，保留原guest采样；不生成host曲线或物理量报告。原有开启组数据和0.480469 MiB最终记账净不足保持，这次关闭组没有新的内存测量。
