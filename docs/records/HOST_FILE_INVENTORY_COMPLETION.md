# host最终文件清单缺项已补入入口（2026-10-20）

**已在host最终mincore入口补入两份依赖目录，以及日志、沙箱记录和模板状态目录。** 真实短恢复的清单根路径由6个扩展为11个，原6个路径及其顺序保持。实现和离线验证完成；本次没有启动沙箱、loop或服务，没有新增真实后备文件驻留结果。

## 新增的五个目录

| 路径 | 覆盖内容 |
| --- | --- |
| 输入来源的`env/deps` | 准备阶段读取的原始依赖文件 |
| 私有卷的`env/deps` | 复制到本轮服务中的依赖文件 |
| 私有卷的`env/logs` | 服务和ublk进程日志 |
| 私有卷的`env/persisted-sandboxes` | 沙箱记录数据库及其日志 |
| 私有卷的`env/template-builds` | 模板状态数据库及其日志 |

路径由`host_file_monitor.backing_roots()`统一选择，`validate_isolated_agentenv.py`实际清理入口调用它，然后复用原`residency_check()`。普通无RAM种子路径为8个根、带种子路径为9个根、带种子的短恢复路径为11个根；快照目录仍只在原恢复分支加入。

查询时机不变：本次写入进程退出后、卸载和删除私有卷之前。只枚举文件元数据并用`mmap(PROT_NONE)`和mincore查询，不读取依赖或数据库内容，不预读或锁页。仍按设备号和inode去重，目录中的符号链接不作为普通文件扫描。

新增目录不存在时沿用原规则抛出`FileNotFoundError`；实际入口把路径记录到`cleanup.host_file_residency_error`，将本次检查判为失败，不跳过后声称完整，也不补零。目录存在但为空则保留该根路径，按当次实际文件枚举结果报告。
