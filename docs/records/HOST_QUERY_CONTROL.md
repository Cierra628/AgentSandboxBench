## 开关只影响驻留查询

外层新增`--rootfs-residency on|off`，默认`on`。选择传过完整组入口、隔离后端的预检查和实际参数重建，最终以`--host-full-rootfs-residency off`进入文件观察器。第一版关闭仅用于显式共享完整GRPO，原共享／独立副本和BPO默认行为保持；现有`--host-sampling`含义不变。

关闭时仅跳过采集程序的`mincore_file`调用，仍保留：

- P0准备清单，以及P1实际文件清单、层顺序、七个VMM引用和daemon分配记录核对；
- 按文件身份去重、每文件七个使用者、查询前后的cgroup计数和文件身份检查；
- P1后的文件与VMM身份复查；
- 原guest采样器、host周期计数、任务调度、官方检查、并发收尾及原计时边界。

关闭组观察器在身份检查完整通过后记为`VALIDATED`；P0／P1均为`NOT_MEASURED`，容量为`None`，每文件记录同样标为未测。实际元数据处理用时照常记录，不填0耗时或0占用。后端、组执行和报告只在显式关闭时接受这一状态；旧默认仍要求`OBSERVED`，失败状态始终拒绝成功。原共享收益汇总不接收关闭查询组。

原执行器会先完成原结果检查，再判定新增文件观察是否通过；本次补齐了执行器自身的测量失败判定，不再只依靠外层发现文件观察失败。任务动作、顺序和检查内容未变。
