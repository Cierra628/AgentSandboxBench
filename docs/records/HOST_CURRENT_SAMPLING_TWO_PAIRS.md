- 两对的原动作回放分别变化−0.30%、−3.76%。负值是实测差值，不解释为采样产生提速。

冷启动调用含客户端进程、HTTP等待和服务返回。保存数据没有服务内部阶段时间，尚不能进一步确定先运行组较慢的内部原因。两对保留全部数值，不用旧guest-only、GRPO或带PSS的结果补出统一减速率。

原计时范围保持：工具累计只加命令用时；回放含原动作、执行通道和结果下载；控制程序整轮还含创建、准备、检查和guest清理。外层入口还含前置输入准备、卷／私有服务、报告和外层清理，不含源服务启停。缓存准备内层计时不含此前归档校验，不能直接拿它与外层相减当作任务时间。

**当前轻量入口、任务语义和曲线可以交付；这两对给出实际耗时范围，不支持固定的“采样减速X%”。** 不为得到更小百分比继续增加本任务轮数。
