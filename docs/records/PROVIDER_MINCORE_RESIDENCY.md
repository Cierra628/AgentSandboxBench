## 最小候选只去掉重复整数转换

当前批量分支将NumPy无符号整数转为Python整数两次，一次作为字典键，一次计算驻留向量下标：

```python
residency.update((int(offset), vector[int(offset)-start]) for offset in run)
```

候选先通过`map(int, run)`逐个转换一次，再复用该整数：

```python
residency.update((offset, vector[offset-start]) for offset in map(int, run))
```

两者都只遍历原请求偏移，不截断高位偏移，也不只保留驻留位最低一位。`ctypes.c_ubyte`读取仍返回Python整数；没有新增数组或列表，也不改分段、mincore调用、查询号、表筛选、结果还原或物理归属条件。
