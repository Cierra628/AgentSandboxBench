## 抽样与误差怎么算

- 每点按 `guest_pfn` 排序，等概率、不放回抽 `n = ceil(N × 比例)` 条。每点每档用 Python 3.12 的 `random.Random(20261118 + 100 × 点号 + 整数百分比)` 初始化，连续执行 200 次 `sample(range(N), n)`，共 5,000 次。排序和抽取只用查询前名单，同一档的点间随机流彼此独立。
- 每次按抽中的 guest 页重放 VMM、直接后备、快照下层。保留 guest lifetime 和各层首末观测的稳定性校验。共享 provider 仍取设备级首末两帧，某个物理页需按原规则覆盖所有相关的来源偏移，并通过 `current` 归属校验。如果某个偏移在查询前对应多个候选别名，只有已查齐该偏移的别名才确认，避免漏掉状态冲突的未抽中页。五点的有效直接后备偏移均无候选别名。
- 设样本四来源确认的 PFN 并集为 `U_S`，主表用 `T̂ = (N/n) × |U_S|`。一条记录可以给并集贡献多张不同的物理页，同一 PFN 被多来源或多个候选命中时只计一次。无确认结果的记录不给并集增加 PFN，其物理占用继续标为未知，估计目标限于**原全量能确认的页数**。主估计量所需的信息均来自本轮的采样与共享帧。它对多候选重复命中的 PFN 可能高估，对需要联查的 provider 页可能低估。实测存档中，前三层去重后的每个 PFN 只由一条候选命中，设备新增页有 18–115 张／点需联查两条候选。跨分支的 PFN 共享关系未由这五点重放检验，不能把各分支估计相加当作七路物理并集。
- 误差按 `e = (T̂ − T) / T`，报告 `|e|` 中位数、`|e|` 最近秩 P95（200 次中的第 190 小值）、`e` 的均值（有符号偏差），以及 `P95(|T̂ − T|) / 256` MiB。五点各自 P95 均 ≤5% 才算达到抽样精度。同为 5% 的原 `segments_v3` 偏离占比是另一个验收指标，原闭合口径照用。按 4 KiB／页，37,352 和 37,514 页的 5% 精度线分别是 **7.295 MiB** 和 **7.327 MiB**。

另算一个**可用于离线分析，不能直接部署**的全量去偏对照。同一批抽样里，给每个已经确认的 PFN 权重 `1/π`，再加总。其中 `π` 是至少抽齐它一组确认所需候选的概率。若任一条都能确认且有 `m` 条独立候选，`π = 1 − C(N−m,n)/C(N,n)`。若必须联查指定的两条，`π = n(n−1) / [N(N−1)]`。有多组可选确认路径时按并事件用容斥计算。权重需要当点的全量 PFN 关联和有效归属，因此仅作离线对照。点 4 的 5% 去偏 P95 是 **5.330%**，高于主估计量的 **4.137%**，低入样概率的联查页一旦抽中会有很大的权重。在这些已存点上，去偏提升了对联查页的补偿，但 5% 档的尾部误差失守。

## 时间预算

`HANDOFF.md` 的约 9 µs 来自约 26 万个**已确认物理页**的工作量估算。阶段报告中点 1 的保留耗时 `336.388 ms / 37,514 ≈ 8.97 µs`，分子仍混有多来源查询和归属，不具备边际计费的含义。这里把 9、12、16 µs／确认 PFN 等价量用作独立的可变成本假设。以同一点的 `T/N` 换成每候选的等价成本，按 `V(n) = c × (T/N) × n / 1000` 得到毫秒。换算使用全量结果标定时间场景，主表的抽样并集估计量无需输入 `T`。

只有直接后备和快照下层的首末四个物理查询阶段按样本规模缩放。其余单分支整点时间扣除两次 provider 查询后记为 `F`，保留 guest 双导出和解码、位置计算、VMM 三次全槽读取、分支级归属和未分项时间。基线 VMM `_bulk` 全读 KVM 槽位，少抽候选不会缩小这三次读取范围。历史单实例首末 provider 调用的合计 `P` 作为一次共享设备观测的代理，含元数据、页表、构建结果，七路只付一次。原测量线程和组级墙钟的定义见 [七路实现](../../scripts/seven_restored_pages.py)。

令 `L = F + V(n)`。**单实例**为 `L + P`，**七份串行工作量**为 `7L + P`，**七实例理想并发墙钟**为 `max(L₁,…,L₇) + P`。各点取七份同规模的已存单实例负载，理想并发数值等于单实例预算。线程争用、同步屏障、抽样路径新增开销、批级 PFN 合并及留证开销仍未知。在这些开销取零的场景下，点 0 的 5% 档按段的 `L≈265 ms`、`P≈197 ms`，若 `P` 保持这个量级，本地阶段有效耗时需低于 `L` 的约 3.03 倍才有可能 `<1 s`。

用归档偏移额外复算标量路径的连续段数。每层对非未知偏移去重排序，遇到不连续就新起一段，每层首末各查一次。在**按段计费**的替代场景里，每层的可变成本用该层完整查询的实测 elapsed 乘以抽样后与原全量的段数比，作为开销主要随调用次数变化的敏感性估算。每次抽样都计算两层调用次数以及 `F + P + 两层可变成本`，表中给出调用次数和时间的 P95。这个模型没有区分每段启动、连续页数、用户态读回和竞争，不能作为实际耗时上界。

首点抽 5% 时，标量调用 P95 为 **4,208 / 8,468**，仍约占原全量的一半。25% 档可拆出更多短段，首点调用 P95 达到 **17,048** 次。历史立即查询七路首轮实际 **10.264852 s**，同一轮 guest 两次读取起点相隔 **5.065–5.069 s**，候选从 30,044–30,228 条降到 2,519–6,502 条。另一场较轻负载的实验后 59 轮中位 **1.269411 s**，56 轮超过 1 秒。这些历史实测与本次的五点同规模推算对应不同负载，不能用原墙钟直接乘抽样比例，或者据此校准七路抽样并发。亚秒也不能证明七份数据严格同刻。
