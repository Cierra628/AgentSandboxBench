## 新增的来源证据来自实际页记账与调用栈

探针从guest任务启动之前开始，覆盖实际测量组的文件缓存事件、私有卷内文件以及明确指定的loop后备镜像。读取文件身份、页大小、偏移及folio的实际内存记账组，记录加入和移出；采集进程从创建起位于测量组之外。

保存的事件显示：

- 后缀结束后的整个探针观测期间，后备镜像有**493.910 MiB缓存加入记录**。其中491.824 MiB发生在任务结束后第11—12秒；当时本组任务已经结束，功能／官方评测接近完成，不能计入原工具执行时延。
- 已记录的这些加入中，492.023 MiB记在本轮控制程序或私有服务所在组，**1.191 MiB记在测量组的父组，0.695 MiB记在根组**，两者合计1.887 MiB在本轮统计范围外。执行者是loop工作线程，线程组不能替代实际页记账组。
- 后备镜像加入事件的调用栈包含`ext4_buffered_write_iter → ext4_file_write_iter → lo_rw_aio → loop_process_work`，直接确认了loop写入后备文件时产生缓存这一来源。这里的栈是针对加入事件累计的，不为每一笔组外加入指定相同调用栈。

这些是**已观察的缓存加入量**，不是观测结束时仍驻留的净占用；缺失事件可能包括移出，不能把加入量补到file曲线上。最终1.488 MiB净差也不能用1.887 MiB直接抵扣，时间和覆盖范围不同。

本轮没有复现旧任务期0.3秒增加514.559 MiB的幅度。本轮最大三个连续采样间隔在放行后0.129—0.429秒，file增加48.254 MiB；对应已保存事件中，共享内存设备的加入量为44.672 MiB，且这个窗口发生事件丢失。因此不能把它写成精确归属比例。旧轮的约515 MiB没有逐页事件，原未知状态保留；本轮说明后备镜像写入缓存会跨越任务阶段，不能只减去一次准备基线就假定后续公共成本不变。
