## 新模式会多记录什么

原完整入口显式开启`host_shared_files`时生效，记录版本为`full-shared-files-v2`。没有开启该选项的普通轻量入口、递增短实验和旧PSS默认行为不变。原用法和配置见[完整模式说明](HOST_FULL_SHARED_IMPLEMENTATION.md)。

只在全部原路径结束、官方检查和删除前的`paths-finished`阶段增加读取：

1. 从实际绑定VMM的驱动清单确认唯一`user_rootfs`块设备，不用保留卷槽代替。
2. 从同一VMM工作目录读取`overlaybd/image.json`，保存配置文件身份、有序lower引用、可写upper的路径和未查询状态。
3. 显式`file`优先；`dir`按OverlayBD规则依次找`overlaybd.commit`、`overlaybd.sealed`。相对路径以运行配置目录为准，绝对路径经该VMM的`/proc/<pid>/root`解析，保留其实际挂载视图。
4. 只用文件元数据核对本地普通文件身份，并要求自有服务已有对应打开描述符。目录中没有本地文件、仅远端引用、没有打开依据或配置读取失败的项，保留`UNKNOWN`和空驻留字段。
5. 每个确定的文件记录所有引用沙箱、引用它的恢复模板和路径别名。模板表示该实例从哪里恢复，不代表该层何时生成；文件来源标为`ACTIVE_ROOTFS_LOWER`，不冒称本轮保存产物。

实现：[`host_rootfs_layers.py`](../../scripts/host_rootfs_layers.py)，接入：[`host_rollout_shared.py`](../../scripts/host_rollout_shared.py)。自有服务打开描述符清单只枚举一次，同时供原内存层核对使用；不读取进程内存或PSS，也不读层文件内容。

## 去重和未知项如何处理

普通文件按`device,inode`（文件所在设备及inode编号）去重。硬链接合并，复制后不同inode分开；digest、路径名称和虚拟盘设备号都不作为普通文件的物理去重依据。同一文件在同一沙箱重复引用，不会增加使用者数量。

| 关联结果 | 记录状态 | 是否查询驻留 |
| --- | --- | --- |
| 至少两个活实例确认引用同一本地文件 | `SELECTED` | 是，整批一次，类别`shared_rootfs_layer` |
| 只有一个确认使用者 | `NOT_REQUESTED_SINGLE_USER` | 否，驻留为空 |
| 无法解析／确认的lower | `UNKNOWN` | 否，驻留为空 |
| 可写upper | `NOT_REQUESTED` | 否，驻留为空 |

关联表整体状态为`IDENTIFIED`或`INCOMPLETE`，报告单列`rootfs_coverage_status`。整体为`INCOMPLETE`时，仍可报告已经确认并成功查询的指定对象；不能把已有对象的`OBSERVED`解读为系统盘下层全部覆盖。旧记录不补造下层身份或驻留。

读取配置前后检查文件身份／大小／修改时间；驻留查询后再检查配置、系统盘设备和已确认下层文件。发生变化时保留测量失败，不输出过期关联的成功结果。原“附加查询失败后仍完成官方检查”的流程保持。

## 成本单列，不重复计入

系统盘元数据读取在最终阶段内，发生在驻留查询开始前，已经计入原`metadata_elapsed_ns`及线程CPU合计；它发生在原路径结束之后，不塞进工具用时。系统盘查询复用`mincore_file`，逐对象记录时段与线程CPU，已经计入原`query_elapsed_ns`。

报告新增：

- `rootfs_metadata_elapsed_ns`／`rootfs_metadata_thread_cpu_ns`：描述符枚举和系统盘关联表读取的用时／线程CPU。
- `rootfs_query_elapsed_ns`／`rootfs_query_thread_cpu_ns`：新增共享系统盘文件的驻留调用用时／线程CPU之和。
- `rootfs_inventory`：原始引用、实际文件身份、使用者、排除及未知项；位于最终阶段和最终查询记录中。

以上是原合计的组成部分，不再次加到整轮时间。原工具累计、创建及原路径用时、驻留查询和包含查询的整轮用时仍分开。系统盘下层驻留也不与块设备、快照内存层或组内file相加为整体RAM。

v2将内存层和系统盘共用的一次打开描述符枚举计入最终阶段元数据；v1的内存层枚举在驻留查询时段内。跨版本比较时应同时查看元数据、查询和整轮时间，不将这部分计时位置变化当成查询加速。

## 离线验证结果

测试只操作自行创建的临时元数据／空文件，驻留、设备、服务和proc操作使用模拟，没有连接真实服务或读取任务输入。新增用例覆盖：

- 硬链接去重、同沙箱重复引用、只在部分沙箱共享、同digest复制文件分开。
- `file`优先、目录commit／sealed顺序、配置相对路径和VMM根目录路径。
- 缺失目录、远端引用、没有打开依据、损坏或缺失配置均保留未知。
- 配置读取期间改变、查询后配置／下层文件替换，以及保留槽不能代替系统盘。
- 只在最终阶段采集，新增共享文件只查一次，成本分列且PSS关闭。

原完整模式及轻量成对测试继续覆盖原调度、保存顺序、两模板去重、原官方失败、查询失败后的官方检查、配置与旧入口默认行为。两份旧真实结果仅重生成报告，原数据未修改，没有借旧结果补出新物理量。
