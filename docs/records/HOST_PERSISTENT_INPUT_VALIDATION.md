## 新文件来源和驻留交叉核对通过

统计组外恢复已验证的备份，临时镜像逻辑20 GiB、实际分配20 GiB加16 KiB；组内首次创建并填充105个普通文件，逻辑7026.389 MiB，记录新设备号／inode等身份。按原协议校验内容并仅同步自有文件和目录。临时来源正常卸载、分离、删除后，才创建运行卷和私有服务。实际运行中的种子检查通过，确认来源释放先于导入完成，导入先于准备基线。

在第二窗口及其端点结束之后，对这105个输入文件执行一次mincore（查询已有文件缓存是否驻留，不读取文件内容），按设备号＋inode去重并核对身份：

- 唯一对象105个，驻留合计 **7026.695 MiB**；比逻辑字节略大是按页计数、末页取整。
- 查询前后统计组file均为 **7360.258 MiB**，驻留量没有超过组内file，检查差额为0。
- 查询墙钟 **0.178369秒**、线程CPU **0.176850秒**，不计入两个5秒窗口。
- `ownership=NOT_QUERIED`：本轮用新文件组内首次填充的来源证据和容量交叉核对，没有逐页查询组内／组外归属。差额0不是实测所有对象组外占用为0。

驻留范围只有这批普通输入。统计组外程序页、节点服务和其他既有对象未因此取得完整归属；current仍是本组记账，不是整个host所有相关页的去重物理并集。原全文件收尾扫描继续为NOT_REQUESTED，新输入查询单独为OBSERVED，两者不混淆。
