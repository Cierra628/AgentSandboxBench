## 对照方法

七支各自冷启动，按同一冻结轨迹共执行 189 个动作。两组都从控制器即将创建七支时开始计时，到所有支的官方检查结束为止（`rollout_end_monotonic_ns − rollout_start_monotonic_ns`）。不含准备服务、准备卷和事后清理。每次单独准备并释放种子、启动和清理私有服务，不用上一轮的沙箱或快照。

基准是[已完成的测量跑](../grpo-per-action-20261121/REPORT.md)，不是另一天的历史对照。三次对照沿用同一冻结输入、Prettier 镜像种子、诊断内核 `6.1.175-asb-cache-v3`、私有诊断服务程序、VMM 进程分组和网络选择。准备前沿用严格大于 58 GiB 的空间检查，正式卷 16 GiB，启动前还按原规则检查可用内存和剩余空间。

测量开关使用现有的 `monitor-mode off` 和 `--schedule-sampling-control`；保留 `--schedule-smoke-metrics` 以保留相同本地输入环境，在 off 模式不执行终点查询。关闭 `--light-rollout` 和 `ASB_GRPO_COLD_ACTIONS`：前者开启周期采样，后者把逐动作放行、暂停和缓存核对连在一起，不能只关读取却把等待放行留下。也不启动整组内存采样。入口仅新增“诊断内核及原服务程序 + 关闭测量”的组合，未改业务重放、官方检查或页数判定。磁盘安全检查照常运行。这个对照测的是整套测量的影响，不能单独分出 PSS、缓存查询或暂停各自造成的延迟。

## 如何读这三个时间

- **整轮墙钟差**是回答“测量让任务慢了多少”的指标：在相同业务结果下，用开测量的完整用时减去关测量的完整用时。开测量只有一次；差值也包含当次机器状态与调度波动。
- **15.445 秒**是动作结束后，从收到就绪通知到放行返回的窗口并集。某支在测量时，其他支仍可工作；反过来，后台采样、等待通知等成本不必落在这些窗口内。它不是新增墙钟。
- **8.456 秒**是至少一支已暂停的墙钟并集（暂停完成到发出恢复请求），是测量窗口的一部分；逐支相加才是 **12.005 沙箱·秒**。暂停的支不一定是决定整轮结束的那一支，两者都不能当作整轮拖慢值。
