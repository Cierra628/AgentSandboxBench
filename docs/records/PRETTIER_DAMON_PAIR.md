# Prettier默认开启与任务期间关闭DAMON对照（2026-10-19）

## 本轮只做一对

先执行默认开启DAMON的一组，再执行任务期间关闭DAMON的一组，各完整29步，共两次。两组均使用原6.1.175 guest内核、2 CPU/4096 MiB、8 GiB私有卷、新guest和0.1秒内存/DAMON采样。比较实际状态、成功回收计数、Cached曲线及工具/重放/控制程序耗时；原动作、补丁和选定测试结果必须保持。没有额外校准，不因缺少下降或耗时方向而追加轮数。

开启组复用`platform-prettier6604-damon-observe.json`，不写回收参数。关闭组使用显式配置`platform-prettier6604-damon-disabled.json`：guest创建后、任务准备及采样之前保存原启用状态，写`enabled=N`，等`kdamond_pid=-1`再继续。采样结束并回收采集进程后，恢复原启用状态并等待对应线程状态就绪，再删除本次guest；失败清理也会尝试恢复。恢复开启会创建新的DAMON线程，不要求线程号或累计计数与停止前相同。

只修改本次guest的启用参数，不修改host、其他沙箱、内核或服务配置，不暂停沙箱，不预读任务文件、清缓存或锁页。普通轻量配置行为保持。关闭DAMON不关闭内存压力下的其他正常回收，也不禁止文件删除或截断导致的缓存减少。

## 核对关闭是否确实生效

关闭组应满足：采样从回收线程退出后开始，全部样本`enabled=N`、`kdamond_pid=-1`；整个采样窗口尝试及成功回收计数增量均为0、没有计数重置；恢复操作在末次采样之后发生，原启用状态恢复成功。Cached是否严格上升不是功能通过条件。

两组是新guest，不预先填充或归一化缓存，需报告首个采样点的差异。单个顺序对照只提供本轮实际差值，不作为稳定减速率。此次数据与此前18次采样开关对照及一次只读观测分开报告。
