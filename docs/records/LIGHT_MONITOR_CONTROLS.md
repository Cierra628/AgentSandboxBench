# 0.1秒轻量采样与关闭采样对照（2026-10-19）

## 本次要回答的问题

将轻量模式从每1秒改为每0.1秒读取guest的`/proc/meminfo`，观察更密集的内存和Cached曲线，并量化采集对任务耗时的影响。指标定义保持：工具命令使用原单调计时；内存为`MemTotal−MemAvailable`，page cache为`Cached`，均不是host物理占用。

此前三任务各一次1秒采集不能回答关闭采样时任务会快多少。本次固定每个任务3对开启/关闭采样对照，共18次完整任务。各对紧邻执行，每轮交换先后顺序，同时反转第二轮的任务顺序；保留所有正负差值，不因波动追加轮数。每个任务第一对兼作新路径验证。

## 两组的差别

- 开启：一个guest进程每0.1秒读取meminfo，保留原工具边界采样和阶段标记，不启动CPU/I/O、host或VMM采集。
- 关闭：不启动周期采集，工具边界的内存/vmstat读取和阶段标记也关闭；原命令、命令时延记录、退出码、输出、补丁和完整选定测试检查保留。

因此对照量化的是当前整套轻量采集的影响，包含既有边界记录成本，不单独归因为周期读取meminfo。关闭组不输出内存曲线或零占用峰值。

两组都使用AgentENV原guest内核、2 CPU/4096 MiB、独立8 GiB卷和新guest，没有额外启动本项目的缓存回收控制器、预读或锁页，不清理host共享缓存。AgentENV默认的DAMON后台回收保留开启；因此这里不是关闭所有自动回收的条件。现有备份校验、磁盘保护和成功后定向清理保持。只启动保留的实验源服务，结束后恢复停止，不替换服务。

## 比较哪些耗时

主要比较原工具命令耗时合计，每对变化为`(开启÷关闭−1)×100%`，汇总3个配对变化的中位数及范围。另列完整原动作重放经过的时间，以及控制程序用时；后者包含guest准备、监控启停、任务和选定测试，不能代替工具命令耗时。既有1秒运行不混入本轮对照。

三对只能说明本轮观察到的影响和波动，不用单个差值推断固定开销。是否保持任务结果与耗时变化大小分别判定，不设置额外性能门槛。

### 为什么此前1秒曲线近似上升，第一轮0.1秒曲线却反复下降

这两张图来自不同次沙箱运行，不是同一次数据改变显示密度。离线将第一轮0.1秒数据抽成约每1秒一个已有点后，下降仍然明显：约3秒186.039 MiB→4秒113.422 MiB，15秒138.629 MiB→16秒50.336 MiB。下降持续到后续采样点，不能只解释为此前1秒采样漏掉了短暂变化。抽取时选每个整秒之后最近的原点，不平均或插值。

相同0.1秒频率的第二轮反而近似持续上升，196点中相邻最大下降只有0.563 MiB；第一轮和第三轮分别达到80.102、122.457 MiB。原1秒那次21点的相邻最大下降为1.227 MiB。采样频率本身不能单独解释这些运行之间的形状差异。

核对四次保存的`isolated-config.toml`，Firecracker及内核设置相同，启动参数均包含`damon_reclaim.enabled=Y`、`damon_reclaim.skip_anon=Y`。DAMON是内核根据访问情况识别并回收不常使用内存的机制。任务读取文件会增加缓存，默认后台回收可能使它下降；这四次旧运行没有记录实际DAMON状态与逐次回收计数，不能逐段补认来源。随后[一轮补充观测](PRETTIER_DAMON_OBSERVATION.md)确认默认DAMON实际回收247.559 MiB，四段明显Cached下降均对应计数增长。该轮实际6.1.175内核未提供`skip_anon`参数，因此此前据启动字符串认定“跳过匿名页、只回收文件缓存”的说法撤回，累计量应称为成功回收内存，不能全部归为文件缓存。

两次实际保存的采集程序相比只改了周期设置，`Cached`定义和读取代码未变，没有新增清缓存操作。此前“无主动缓存回收”的说法现已明确为“没有额外启动本项目的回收控制器”，不表示AgentENV默认后台回收关闭。

对比图：[PNG](evidence/prettier-light-curve-review-20261019.png)、[SVG](evidence/prettier-light-curve-review-20261019.svg)。上图是此前1秒运行，中图叠加第一轮0.1秒及其每秒抽点，下图是第二轮0.1秒运行；已实际查看。脚本、逐点数据、配置核对和采集程序差异位于`.artifacts/light-prettier-curve-review-20261019/`，没有重跑任务或启动服务。源码依据为`AgentENV/src/sandbox/firecracker/config.rs`的默认回收参数，以及`sandbox.rs`中DAMON回收文件缓存、balloon上报空闲页的配置说明；实际是否执行以运行时计数为准。
