## 1. 归属先区分三个问题

## 2. guest缓存页仍在加入、移出时维护

现有`ASBCACH1`与原`/proc/asb_pagecache`不改：

- 表级范围：`sandbox_id + guest_boot_id`，另由PID、进程启动ticks、MMDS、实际出生cgroup和KVM注册证明连接到当前VMM。恢复后即使guest boot相同，也必须使用新沙箱/新VMM会话身份。
- 页级键：`guest_pfn + lifetime_tag`。完整键为`(sandbox_id, guest_boot_id, guest_pfn, lifetime_tag)`；不能跨guest只按PFN或inode合并。
- 页加入普通文件/shmem缓存时生成新生命周期，移出时注销，页迁移走已有移除/新建路径。物理页号复用不沿用旧标签。
- tag最低位区分普通文件与shmem，其余位是本次guest启动内不重复的生命周期号。采样记录当前成员，不累计历史加入量当占用。
- 导出快照期间变化、重复加入、缺失移除、超出PFN范围和迁移计数保留原检查。错误不填零、不关闭回收、不锁工作负载页。

**这些页表上下文已足以区分“哪个guest的缓存”。逐文件拆分才需要文件身份；不能因全guest表没有inode就否定现有逐guest容量统计。**

## 3. 文件身份沿用独立查询，不冒充全覆盖

## 5. 存储和采集成本必须记录

继续使用原严格小于1 GiB/会话的原始二进制预算，新文件计入其中，超限在写本点RAM文件前报错，不截断、不放宽。原卷大小、磁盘门槛、采样周期、等待上限和segments_v3不改。保存产生的额外CPU、写盘和文件缓存有真实成本，不能用24 MiB从父组current中扣除。

本次实测A/B分别18/19点，新增RAM证据432/456 MiB，原始二进制总量444.348694/468.585159 MiB。RAM保存CPU为0.781959/0.807479秒，收尾分析CPU为0.385318/0.388151秒；后备对象查询主线程墙钟0.250337秒、CPU 0.178250秒，worker另列。未做采集开关对照，这些是处理成本，不是相对性能损失。

RAM原始PFN只保留本地，不上传。普通路径不开此选项，也不新增RAM文件或采集动作。旧数据没有完整RAM行时为UNAVAILABLE，不能用缓存行补齐空白。

## 6. host后备对象和共享引用：一次实跑通过，覆盖仍不完整

复用已有采集器，不另建一套host页分配打标系统：

- 对象清单包含19层、每guest可写层、rootfs/工具块设备、loop后备文件；设备身份与文件身份分开，保存实际配置及引用沙箱集合。
- 普通文件按本查询窗口内设备号/inode及前后身份去重，mincore必须确认有效权限；设备用现有有效的cachestat方法。能力不具备记UNKNOWN/UNAVAILABLE，不改成读取内容触发驻留。
- 同一对象可有多个沙箱引用；只保存“引用集合”，不假定每一页都被每个引用者实际访问，也不把I/O调用者当成唯一拥有者。
- host对象查询保存时间窗和未知项。仅有mincore位图时给对象驻留容量；没有PFN证据就不声称与VMM RAM做完物理页去重。
- cgroup父/子四分项继续保存，父包含子不相加；file含shmem，dirty/writeback为状态子项。记账闭合不等于对象覆盖完整。

实现为`host_backing_evidence.py`，通过默认关闭的`run_live_child_calibration.py --host-backing-evidence`接入。先停止guest缓存采样器，再在VMM仍存活时做一次后备对象查询，之后才结束合成文件程序和删除VMM；对象查询不与前面的RAM读数宣称同时。原采样间隔、预算和等待上限不变。

输出`host-backing-raw.json`保留实际drives、lower/upper、普通文件、块设备、TMPFS和loop的完整原结果；`host-backing-evidence.json`按对象身份列出驻留查询及引用沙箱。普通文件按设备号/inode合并，块设备按已固定且校验的rdev合并；同inode的TMPFS结果独立关联，不能混入普通磁盘文件。文件与设备、loop等层之间不生成相加总量。

配置/打开文件/映射能证明引用，不证明每个缓存页都被该沙箱访问。服务或控制程序独有对象没有可靠guest引用就保留UNASSIGNED；外层卷只标“包含这批沙箱的文件系统”，不把整个卷缓存记到每个guest。记录页实际记在哪个cgroup仍为NOT_MEASURED，不能从组总量反推。

代码身份冲突或权限前置检查失败会保存FAIL并上报；单个对象查询失败保留UNKNOWN，清单不完整保留PARTIAL。完整逐沙箱host内存/缓存字段留空。前置离线重放见`results/host-backing-evidence-offline-20261115T154810Z/final/REPORT.md`；旧双沙箱记录仍为UNAVAILABLE，不补入本次值。
