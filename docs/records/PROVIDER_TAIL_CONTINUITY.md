# 旧缓冲尾部的离线时序核对（2026-10-16）

**现有记录可以证明27次较短读取后仍保留部分旧尾部，每次4–116 KiB。** 代次和完整读取次数可以在特定条件下补出旧内容区段，但跨过多次读取时仍缺少中间长度，不能普遍恢复全部尾部身份。

输入沿用短恢复`20261016T033725Z-2170673`的`guest-cache/live-cache/restored/`。本机结果为`.artifacts/provider-tail-continuity-20261016/`；[脱敏清单](evidence/provider-tail-continuity-20261016.json)包含27条起止观测、槽号、缓冲字节区间和原快照字节区间。此前的驻留分类见[未归属缓冲报告](PROVIDER_BUFFER_UNKNOWN.md)。

## 代次如何限制两次观测之间的改写

源码依据是已验证私有构建保存的`source/storage/ublk/src/slot_observation.rs`与`dev.rs`，位于`.artifacts/provider-get-data-20261016/`。固定基线为AgentENV `2f48c9c78ec58e4d73c49aa07cb81d984a4a4184`，再应用已有槽位观测和GET_DATA补丁。

- `SlotObservation::update`每次先加1、写字段、再加1，因此每次状态更新使代次加2，更新中为奇数。
- 每次请求在调用目标读写函数之前执行`begin`，完成后执行`complete`。一次成功的完整READ使代次加4，完整读取次数加1。失败、部分读取和非读取请求不增加完整读取次数，但仍消耗代次。
- `get_write_data`在允许内核向缓冲复制之前执行`before_get_data`，另使代次加2；释放也使代次加2。实际协商了GET_DATA，等待下一请求本身不改变记录，内核不会绕过失效通知先写缓冲。
- 每槽由一个任务串行处理并独占缓冲。目标函数`OverlaybdTarget::handle_read`只把`user_buf.subslice_mut(0, len)`交给读取函数，成功时检查返回长度等于请求长度；因此每次READ只覆盖从缓冲起点开始的前缀。固定基线的这段代码已另存本轮结果目录，当前补丁未修改它。

对同一进程、设备、队列、槽及分配生命周期的两个完整读取成功状态，设代次差为ΔG、完整读取次数差为ΔR。两端各自的元数据前后读取必须一致、代次为偶数，地址和容量不变。推断还以计数没有超过整数上限后重新从0开始为前提；本次观测最大代次1818、最大单槽完整读取次数454，所有相邻计数均未倒退。

| 两端差值 | 可以确定的事 | 对旧尾部的处理 |
| --- | --- | --- |
| ΔG=0，ΔR=0，整条记录一致 | 中间没有记录到改写，已知前缀仍保留 | 不凭空给此前未知尾部补身份 |
| ΔG=4，ΔR=1 | 恰好一次完整READ，没有其他填充、失败或GET_DATA复制 | 若新长度小于旧长度，保留区间为`[新长度, 旧长度)` |
| ΔG=4×ΔR，ΔR>1 | 中间只有完整READ，但中间每次长度未知 | 不用最后长度推断全部旧尾部 |
| 其他差值、记录不稳或身份变化 | 可能有额外改写，或无法确定两端状态 | 保持未知 |

保留区间中的快照偏移沿用**前一次**读取：若旧偏移为O，缓冲区间`[a,b)`对应此前读取的`[O+a,O+b)`，不能套用新读取的偏移。

## 304次相邻比较中，27次能给出旧尾部区段

每个恢复点已有前、后两次槽位查询，每次又在物理页号查询前后各读一次元数据。先检查每次查询的元数据前后相同，得到每槽20次有效观测；相邻比较共`16×19=304`次。其中160次位于同一恢复点内，144次跨相邻恢复点。本次所有端点均稳定有效、分配身份一致，全部差值满足ΔG=4×ΔR。

## 为什么不能直接扩大缓存物理并集

**38次多次读取之间仍存在信息缺口。** 例如原来已知8 KiB前缀，之后发生两次读取，最后一次长度为2 KiB：前一次可以是2 KiB读取，也可以是16 KiB读取。两种历史的代次、次数和最后偏移/长度完全相同，但`[2,8) KiB`是否保留旧内容不同。提高最后一次记录的可信度不能补出缺失的中间长度。

本轮仅证明直接相邻观测之间的部分内容保留，没有沿后续观测传递、拼接所有历史区段。218次无改写比较可以延续已有内容，但不会说明采集开始前未知的尾部是什么。

即使某段旧字节身份已知，计入当前缓存物理量还须在同一配对区间确认：整个host页的所有字节都有归属、缓冲物理页号稳定、对应guest文件缓存页身份稳定，以及写时复制后它属于当前版本还是旧快照副本。相邻时刻内容连续不等于物理页号始终相同，也不等于该内容仍属于当前guest缓存。因此本轮不改原4036 KiB完整缓冲驻留量及其分类，不把27条直接加入并集。
