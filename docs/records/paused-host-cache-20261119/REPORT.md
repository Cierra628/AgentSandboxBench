## 适用范围与证据

旧记录的 37,352 页是按 guest 缓存归属确认的物理页，不是此 inode 的全文件驻留页数。本轮没有同文件、同时间窗、不中断运行的成对对照，不能用两数相减判断暂停的因果效果。本轮定时点均稳定，但没有观察点间瞬态、相同偏移的物理页号或 30 秒之后的状态。宿主可用内存充足；不外推到内存压力下，也不把此文件的 73,714 页全部计为该沙箱的独占缓存。
