新统计组在准备输入前创建。创建guest前确认组内没有Firecracker，三个池与预热开关关闭；实际测量组的`cgroup.subtree_control`包含`io`，私有Docker服务存在`io.stat`。这些状态保存于本轮`host_file_creation.io_controller_state`，不只依据启动参数判断。

父guest及三次恢复的原动作、退出码、文件/进度检查和探针进程连续性通过。N=2的两个实际VMM映射到同一个4 GiB内存后备设备；按设备身份去重，退出后设备释放再进入下一阶段。
